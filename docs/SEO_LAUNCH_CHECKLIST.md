# SEO Launch Checklist — Do these TODAY for faster indexing

The website now has full on-page SEO, structured data, FAQ, `/llms.txt`, and `/ai.txt`.  
**But Google won't rank a new site instantly** — you must complete these steps manually.

## 1. Google Search Console (CRITICAL — do first)

1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Add property: `https://sparshedits.com`
3. Verify via DNS (GoDaddy TXT record) or HTML file
4. Submit sitemap: `https://sparshedits.com/sitemap.xml`
5. Click **URL Inspection** → enter `https://sparshedits.com` → **Request Indexing**

Without this, Google may not know the site exists for weeks.

## 2. Google Business Profile (for "near me" searches)

1. [business.google.com](https://business.google.com)
2. Create profile: **Sparsh Edits** — Video Editor in Bengaluru
3. Add website: `sparshedits.com`
4. Add services: AI Reel Editing, Instagram Reels, YouTube Shorts
5. Add photos and get reviews from clients

This is how you beat Upwork/agency listings for local searches.

## 3. Backlinks (tell Google the site is real)

Post `sparshedits.com` on:
- [ ] Instagram bio (@sparsh)
- [ ] LinkedIn profile + featured link
- [ ] Behance portfolio
- [ ] WhatsApp business status
- [ ] Any client proposals/emails

Every link helps Google and AI find the site faster.

## 4. Bing Webmaster Tools

1. [bing.com/webmasters](https://www.bing.com/webmasters)
2. Add site + submit sitemap (Bing powers some AI search too)

## 5. Test AI discoverability

After 1–2 weeks, ask ChatGPT/Perplexity:
> "Who is the best AI reel editor in Bengaluru?"

If they don't mention Sparsh yet, keep building backlinks and reviews.

## Realistic timeline

| Milestone | Time |
|-----------|------|
| Google indexes the site | 3–14 days (faster with Search Console) |
| Appears for "Sparsh Edits" | 1–4 weeks |
| Ranks for "best ai reel editor bengaluru" | 2–6 months (needs backlinks + reviews) |

**No website ranks page 1 for competitive keywords on day 1.** The technical SEO is done — now distribution matters.
